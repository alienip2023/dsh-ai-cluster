# AI 大一统 · 架构与分期计划

AI 大一统（包名 `dsh-ai-unified`）把几台电脑连成一张 AI 网络：主控派任务、副机执行、统一面板、模型与记忆统一配置。
种子来自 `dsh-remote-agent 0.10.1-fork.93`（hub/node 传输、配对、`remote_*` 工具、侧栏拓扑面板、连通性上报）。

## 分期计划

| 阶段 | 内容 |
|---|---|
| 1 骨架 + 多机 | 以种子为骨架，替代现有 remote-agent（ra）：hub/node、配对、`remote_*` 工具、面板。阶段 1a 只切换身份与文档，不改功能语义。 |
| 2 吸收 dsh-mesh | 局域网发现、TLS 指纹、开机自启、ACL。（局域网发现已在 1b 落地，默认关闭；TLS 指纹、开机自启、ACL 仍属本阶段。） |
| 3 模型与记忆 | 模型配置下发；记忆 scope。 |
| 4 Bot 层统一 | 只有主控有主 Bot；内部 id 在此阶段统一重命名。 |
| 5 交付 | 桌面版与部署版交付。 |

## 端口与服务约束

- 端口沿用 hub 的 **19387**。
- 阶段 2 才引入 dsh-mesh 的 **8124 / 8129**（其中 UDP 8129 的局域网发现已在 1b 以自有协议落地，默认关闭）。
- **禁止同一个包装两套服务**：mesh 能力并入同一个服务体系，不得再并行起一套独立服务。

## 为什么内部 id 暂不重命名

阶段 1a 只换"身份"（包名、版本、显示名、日志前缀），以下内部标识刻意保持不变：

- **服务名 `remote-agent:*`**（`remote-agent:registry`、`remote-agent:bot-message`、`remote-agent:roster-report` 等）：ds-bot 现在依赖这些接口，改名会直接打断 Bot 侧。
- **工具名 `remote_*`**：同属对外接口，本轮不动。
- **`cordis.patch.yml` 中的 `id: remote-agent`**：已安装的 profile 用这个 id 覆盖配置，改了会让旧配置失效。
- 协议帧名、端口：不改。

统一重命名放到**阶段 4（Bot 层统一）**，与 ds-bot 侧一起做，并提供兼容别名/迁移步骤。

## 用户可见名称

侧栏页名、面板标题统一为「AI 大一统」（英文 `AI Unified`）。正文中的「远程同事」是功能词汇，保持原样。日志与告警前缀为 `dsh-ai-unified:`。
